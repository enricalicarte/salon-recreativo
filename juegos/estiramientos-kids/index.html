      Estiramientos kids

      Niños 7–8 años · Después de entrenar
      Sesión de estiramientos suaves para después de entrenar o de un partido, pensada para niños de 7–8 años: cada ejercicio estira un grupo muscular, primero con un lado y luego con el otro. Se mantiene la postura sin rebotes y respirando con calma; el estiramiento debe notarse, pero nunca doler. Pautas generales; no es un programa oficial. Siempre con supervisión de un adulto.
